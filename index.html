What is a Computer?

A computer is an electronic device that processes data according to a set of instructions called a program. It consists of several key hardware components that work together to store, process, and display information.

Modern computers come in many forms — from massive servers to thin laptops — but they all share the same fundamental building blocks.

Core Components

CPU — Central Processing Unit

The "brain" of the computer. It executes instructions and performs calculations for every program you run.

Learn more about CPU →

Motherboard

The main circuit board that connects all components together. Everything plugs into it.

Learn more about Motherboard →

RAM — Random Access Memory

Short-term memory. It temporarily stores data that the CPU is actively using, making everything faster.

Learn more about RAM →

GPU — Graphics Processing Unit

Handles all visual output. Essential for gaming, video editing, and 3D rendering.

Learn more about GPU →

Storage (SSD / HDD)

Long-term memory. Stores your OS, programs, and files even when the computer is off.

Learn more about Storage →

Power Supply (PSU)

Converts electricity from the wall into the voltages that computer components need to operate.

Learn more about PSU →

Case

The enclosure that holds and protects all components. Also helps with airflow and cooling.

Learn more about Case →

CPU Cooler

Keeps the processor from overheating. Can be air-based (fans) or liquid-based.

Learn more about Coolers →

Monitor

The display device. Shows you everything the GPU renders — your main window to the computer.

Learn more about Monitors →

Operating System

Not hardware, but essential. The OS (like Linux, Windows, macOS) manages all hardware and software.

Learn more about OS →
